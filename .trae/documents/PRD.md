## 1. 产品概述

一个面向独立创作者与工程师的个人主页，以「静谧奢华的编辑设计美学」为核心，用杂志式的叙事节奏呈现个人介绍、作品、文章与联系方式。

- 主要目的：以高完成度的视觉与交互，建立作者的个人品牌形象，承载作品集与近期思考（博客）的入口
- 目标价值：让访客在 30 秒内记住主理人，并能流畅触达最近 10 篇博客与核心项目

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|---------|---------|
| 访客 | 无需注册 | 浏览首页所有内容、跳转外链、查看最近博客 |
| 主理人（隐含） | 本地数据维护 | 通过编辑数据文件更新博客与项目 |

### 2.2 功能模块

1. **首页（单页式滚动）**：Hero 自我介绍、关于、精选项目、最近博客（10 条）、联系方式
2. **博客详情**（轻量弹层）：点击博客卡片打开阅读视图

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 首页 | Hero 区 | 巨幅姓名/身份展示，副标题 + 滚动提示，背景含纹理与渐变光晕 |
| 首页 | 关于 | 左右不对称栏：肖像占位 + 个人简介、技能标签、时间线 |
| 首页 | 精选项目 | 网格作品集，卡片含封面、标题、描述、技术栈标签、外链 |
| 首页 | 最近博客 | 列表式 10 条博客，含日期、分类、标题、摘要；点击展开阅读视图 |
| 首页 | 联系方式 | 邮箱、社交链接（GitHub / X / LinkedIn），底部版权与致谢 |
| 博客弹层 | 阅读视图 | 模态层展示正文（Markdown 渲染）、元信息、关闭按钮 |

## 3. 核心流程

访客进入首页 → 视觉首屏（Hero）建立印象 → 滚动依次揭示关于/项目/博客 → 在「最近博客」点击某条 → 弹出阅读视图 → 关闭返回 → 滚至底部联系区跳转外链。

## 4. 用户界面设计

### 4.1 设计风格

- **美学方向**：静谧奢华编辑感（Kinfolk × 建筑摄影集）
- **主色**：温暖奶油底 `#F4EFE6`、深咖啡文字 `#1F1B16`
- **点缀色**：赭石红 `#8B3A2E`、淡金 `#B8956A`
- **按钮风格**：极简文字下划线按钮 + 极少填充按钮（赭石红实心）
- **字体**：展示衬线 `Fraunces`（光学尺寸变量），正文 `Newsreader`，标签/数字 `JetBrains Mono`
- **布局风格**：不对称编辑网格、大留白、12 列基准、章节间纵向呼吸感
- **图标/emoji**：克制使用线性自定义 SVG，不使用 emoji
- **背景纹理**：细微噪点叠加 + 局部渐变光晕

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|--------|
| 首页 | Hero 区 | 全屏 80vh，左侧大号衬线姓名，右侧元数据（地点/时区/状态），底部滚动指示 |
| 首页 | 关于 | 12 列网格，左 5 列肖像，右 6 列留白偏移；技能以「·」分隔的行内文字呈现 |
| 首页 | 精选项目 | 2 列大卡，奇偶错位；卡片含编号、封面、标题、描述、标签 |
| 首页 | 最近博客 | 编号列表 01–10，每行：日期 / 分类 / 标题 / 摘要；hover 高亮整行 |
| 首页 | 联系方式 | 居中邮件 CTA + 右下社交链接组；底部细线分隔 |
| 博客弹层 | 阅读视图 | 居中单栏 720px，顶部元信息，正文衬线，关闭按钮固定右上 |

### 4.3 响应式

- 桌面优先（≥1024px），编辑式不对称网格完整呈现
- 平板（768–1023px）：网格降为 2 列对称，留白适度收紧
- 移动（<768px）：单列纵向堆叠，Hero 字号自适应缩减，导航折叠为顶部抽屉

### 4.4 动效

- 页面载入：Hero 文字 staggered reveal（动画延时 80ms 递增）
- 滚动揭示：各章节使用 IntersectionObserver 触发淡入上移
- 微交互：博客行 hover 背景渐显、项目卡 hover 图像轻微缩放、链接下划线生长动画
- 阅读视图：弹层从中心轻微缩放 + 背景模糊渐入
